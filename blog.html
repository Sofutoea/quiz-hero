Exam

Q1 : How does JavaScript work in the browser?

Answer : JavaScript runs inside the browser’s engine (like V8 in Chrome). It interprets the code line by line and updates the DOM to make web pages interactive in real-time.

Q2 : What is the difference between var, let, and const?

Answer : var has function scope, while let and const have block scope. const values cannot be reassigned, but objects/arrays can still be modified.

Q3 : What is the DOM in web development?

Answer : The DOM (Document Object Model) is a tree-like structure that represents an HTML page. JavaScript can access and modify this structure to change content dynamically.

Q4 : Why is JSON important in JavaScript?

Answer : JSON is a lightweight data format used to store and exchange data. It is easy to parse in JavaScript, making it essential for APIs and server communication.

Q5 : What is the purpose of event listeners?

Answer : Event listeners let JavaScript respond to user actions like clicks, typing, or scrolling. They make web pages interactive and responsive to user input.
