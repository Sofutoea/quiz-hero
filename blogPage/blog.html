Q1 : What is the difference between `var`, `let`, and `const` in JavaScript?

Answer : `var` is function-scoped, while `let` and `const` are block-scoped. `const` is used for variables that should not be reassigned, whereas `let` allows reassignment.

Q2 : What are arrow functions in JavaScript?

Answer : Arrow functions provide a shorter syntax for writing functions and do not bind their own `this`. They are useful in callbacks and functional programming.

Q3 : What is the purpose of the `this` keyword in JavaScript?

Answer : The `this` keyword refers to the object that is executing the current function. Its value depends on how the function is called.

Q4 : What is the difference between `==` and `===` in JavaScript?

Answer : `==` compares values after type coercion, while `===` checks both value and type. It is recommended to use `===` for strict comparison.

Q5 : What are JavaScript promises?

Answer : Promises represent the eventual completion (or failure) of an asynchronous operation and its result. They help manage async code in a cleaner way than callbacks.
