Exam

Q1: What is JavaScript?

Answer: JavaScript is a versatile programming language mainly used for web development. It makes websites interactive and works on both client and server sides.

Q2: What are JavaScript data types?

Answer: JavaScript has primitive types like string, number, boolean, null, undefined, symbol, and bigint. It also has objects, arrays, and functions as reference types.

Q3: What is the difference between let, var, and const?

Answer: var is function-scoped and allows redeclaration, let is block-scoped and re-assignable, while const is block-scoped and cannot be reassigned.

Q4: What is DOM in JavaScript?

Answer: DOM (Document Object Model) is a tree-like structure representing HTML elements. JavaScript can access and modify it to dynamically change content and styles.

Q5: What are JavaScript functions?

Answer: Functions are reusable blocks of code that perform a specific task. They can take inputs (parameters), process them, and return an output.
