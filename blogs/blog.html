Q1: What is the difference between `let`, `const`, and `var`?

Ans: `var` is function-scoped and can be redeclared. `let` is block-scoped and cannot be redeclared in the same scope. `const` is also block-scoped but must be assigned a value when declared and cannot be reassigned.

Q2: What is a closure in JavaScript?

Ans: A closure is a function that remembers the variables from its parent scope even after the parent function has executed. This allows functions to have private variables and maintain state between executions.

Q3: What is the difference between `==` and `===` in JavaScript?

Ans: `==` checks for equality after type conversion, meaning `5 == "5"` is true. `===` checks for both value and type, so `5 === "5"` is false. It’s recommended to use `===` to avoid unexpected type coercion.

Q4: What is the purpose of the `this` keyword in JavaScript?

Ans: The `this` keyword refers to the object that is currently executing the function. Its value depends on how the function is called. In a method, `this` refers to the object, while in a regular function, it refers to the global object or `undefined` in strict mode.

Q5: What is event delegation in JavaScript?

Ans: Event delegation is a technique where a parent element handles events for its child elements using event bubbling. Instead of adding event listeners to multiple elements, a single listener is added to a common ancestor, improving performance.
